- **Application:** TanStack Start <version> (React<!-- or Solid -->) on Vite,
  TypeScript (`strict`), in `<path>`. File-based routes in `src/routes/`;
  `src/routeTree.gen.ts` is generated by the router plugin.
- **Server/client split:** route loaders, `beforeLoad` and components run on
  the server AND in the browser. Server-only code (database, secrets, Node
  APIs) lives under `src/server/` or in `*.server.ts` files and is reached
  through server functions (`createServerFn`, input validated with
  `.inputValidator()` and a zod schema) or server routes.
- **Data:** <database and ORM, e.g. PostgreSQL via Drizzle>; schema changes only
  through migrations. TanStack Query for client cache<!-- if used -->.
- **Config:** env is read and validated once in a server-only module; only
  public values carry the `VITE_` prefix.
- **Tooling:** the lockfile names the package manager (exactly one lockfile;
  `packageManager` pins its version). The `package.json` scripts are the
  command source of truth; `CLAUDE.md` indexes them. <ESLint or Biome>.
- **Tests:** Vitest for unit tests (`*.test.ts(x)` next to the code), Testing
  Library for components, Playwright for `test:e2e`.

`@tanstack/*` packages are pinned to one release and always upgraded together.
